# Virtuelle Unterrichtseinheit „Brennstoffe“ – Blockwoche 1

GitHub-Pages-fähiger Selbstlernkurs für die 12. Klasse. Keine externe Bibliothek, kein Build-Prozess.

## Inhalt

1. Allgemeine Brennstoffkunde
2. Verbrennung
3. Verbrennungsprodukte
4. Dichte und relative Dichte
5. Heizwert und Brennwert
6. Erdgas inkl. Wobbe-Index
7. Flüssige Brennstoffe
8. Feste Brennstoffe
9. Abschlusscheck

Die Lernlandkarte auf `index.html` dient als visueller Einstieg. Die vier Spalten sind auf Desktop anklickbar.

## In GitHub veröffentlichen

1. Den gesamten Ordner in ein GitHub-Repository hochladen.
2. In **Settings → Pages** als Quelle **Deploy from a branch** auswählen.
3. Branch `main`, Ordner `/ (root)` auswählen und speichern.
4. Nach kurzer Zeit ist der Kurs über die GitHub-Pages-Adresse erreichbar.

## Anpassung

- Texte: direkt in den HTML-Dateien unter `units/`.
- Gestaltung: `assets/styles.css`.
- Lernlandkarte: `assets/lernlandkarte-blockwoche1.png`.
- Interaktive Kurzchecks: `assets/course.js`.

## Didaktische Idee

Jede Einheit ist bewusst klein gehalten: Lernziel → kurzer Fachtext → Visualisierung/Übersicht → Arbeitssequenz → Selbstcheck. Richtwert 20–30 Minuten pro Einheit.
